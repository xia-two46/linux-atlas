# 入门路线

从零开始学 Linux，最容易犯的错是「想一口气全学」。其实你只需要一条清晰的路线，按阶段推进。下面是我建议的路径，配合本站的命令手册食用更佳。

## 第一阶段：熟悉环境（1~2 周）

先别急着背命令，先「住进」Linux 环境里。

- 装一个发行版（推荐 Ubuntu，或用 WSL / 虚拟机先在 Windows 里体验）。
- 学会打开终端，理解「shell 是人和内核之间的翻译官」。
- 搞懂**文件系统**：一切皆文件，`/` 是根，`/home`、`/etc`、`/var`、`/usr` 分别放什么。

> 推荐命令：`pwd`、`ls`、`cd`、`mkdir`、`touch`、`cp`、`mv`、`rm`

## 第二阶段：读写文件与权限（1~2 周）

这是使用 Linux 的日常。

- 学会查看和编辑文件：`cat`、`less`、`head`、`tail`，以及文本编辑器（`nano` 上手快，`vim` 值得长期投资）。
- 理解**权限模型**：`rwx` 三组、`chmod`、`chown`、`sudo` 提权。

> 推荐命令：`cat`、`less`、`head`、`chmod`、`chown`、`sudo`、`su`

## 第三阶段：管道与文本处理（1 周）

Linux 哲学——「让每个程序做好一件事，用管道把它们串起来」。

- 理解 `|`、`>`、`>>`、`<` 重定向。
- 学会 `grep`、`sed`、`awk`、`sort`、`uniq`、`wc` 组合处理文本。

> 推荐命令：`grep`、`sed`、`awk`、`sort`、`uniq`、`wc`、`tee`、`xargs`

## 第四阶段：进程与系统管理（1 周）

- 查看进程：`ps`、`top`、`kill`。
- 管理服务：`systemctl`、`journalctl`。
- 定时任务：`crontab`。
- 查看系统信息：`uname`、`free`、`df`、`du`、`uptime`。

## 第五阶段：网络与远程（1 周）

- 网络诊断：`ping`、`ip`、`ss`、`dig`。
- 远程操作：`ssh` 登录、`scp` / `rsync` 传文件。
- 下载：`curl`、`wget`。

这一阶段学完，你就具备了**把本站部署到服务器**的能力——参见 [部署文档](/about/deploy)。

## 贯穿始终的三个习惯

1. **遇到不认识的命令先 `man`**：`man` 手册是最好的一手资料。
2. **动手验证**：本站的 [在线终端](/commands/terminal) 可以让你随手敲命令，看真实输出。
3. **记录笔记**：把自己踩过的坑记下来，是最好的学习成果。

## 学习资源推荐

- **Linux 命令**：本站命令手册 + `man` 手册。
- **深入原理**：《鸟哥的 Linux 私房菜》、The Linux Command Line（免费电子书）。
- **系统管理员路线**：Linux Journey（免费互动教程）。
- **实战**：把自己的博客/项目部署到服务器，是最快的成长方式。
