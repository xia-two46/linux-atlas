# 开源精神

Linux 之所以伟大，不只是因为技术，更因为它背后的**自由软件与开源精神**。理解这份精神，才能真正理解为什么全球数百万开发者愿意无偿贡献代码。

## 一切从 GNU 讲起

1983 年，Richard Stallman 发起 **GNU 计划**，目标是打造一个完全自由的类 Unix 操作系统。他同时创立了自由软件基金会（FSF），并提出了自由软件的**四项基本自由**：

1. **自由之零**：为任何目的运行程序的自由。
2. **自由之一**：研究程序如何工作、并按需修改的自由（前提是能拿到源代码）。
3. **自由之二**：重新分发副本、帮助他人的自由。
4. **自由之三**：把修改后的版本发布给公众的自由。

「Free」在这里是「自由（freedom）」，不是「免费（free beer）」——正如那句名言所说：**"Free as in free speech, not as in free beer."**

## Linux 内核的诞生

1991 年，芬兰学生 Linus Torvalds 在 Usenet 上发帖：

> "I'm doing a (free) operating system (just a hobby, won't be big and professional like gnu)..."

他没想到，这个「业余爱好」后来运行在全世界绝大多数服务器、手机（Android 基于 Linux 内核）和超级计算机上。GNU 提供了工具链，Linux 提供了内核，两者结合成了我们今天说的 **GNU/Linux**。

## 开源许可证

开源不等于「随便用」。不同的许可证规定了你可以做什么：

| 许可证 | 类型 | 关键要求 |
| --- | --- | --- |
| **GPL** | Copyleft（传染性） | 衍生作品必须同样开源，用 GPL |
| **MIT** | 宽松 | 只要保留版权声明，几乎可随意使用 |
| **Apache 2.0** | 宽松 | 保留版权 + 提供专利授权，企业友好 |
| **BSD** | 宽松 | 类似 MIT，条款略多 |
| **MPL** | 弱 Copyleft | 只要求修改的文件开源 |

- 想要「我开源了你也得开源」→ 选 **GPL**。
- 想「随便用，改了我的还是我的」→ 选 **MIT** / **Apache**。

## 开源精神的三层含义

1. **分享**：把代码公开，让别人能学习、复用、改进。
2. **协作**：通过 Git、Issue、Pull Request，全球开发者跨越时区协作。
3. **信任与透明**：代码可见，意味着任何人都能审查，这是安全与质量的根基。

## 我们能做什么？

- **读代码**：去 GitHub 看你每天用的工具的源码。
- **提 Issue**：发现 bug，礼貌地反馈。
- **做贡献**：哪怕只是修一个错别字、改进一段文档，都是贡献。
- **自己开源**：把一个练手项目 push 到 GitHub，附上 README 和 License。

> 开源不是「白嫖」，而是「站在巨人的肩膀上，也让自己成为后来者的肩膀」。
