# Linux 发行版介绍

Linux 不是一个单一的操作系统，而是一个**内核**。围绕这个内核，不同的组织打包了不同的软件、桌面环境和包管理器，形成了「发行版」（Distribution，简称 distro）。理解发行版的差异，是理解 Linux 生态的第一步。

## 发行版家族树

几乎所有的发行版都可以追溯到三条主线：

| 主线 | 代表发行版 | 包管理器 | 特点 |
| --- | --- | --- | --- |
| **Debian 系** | Debian、Ubuntu、Linux Mint | apt / dpkg | 稳定、文档丰富、社区庞大 |
| **Red Hat 系** | RHEL、Fedora、CentOS、Rocky | dnf / yum / rpm | 企业级、服务器主流 |
| **Arch 系** | Arch Linux、Manjaro、EndeavourOS | pacman | 滚动更新、极简、可高度定制 |

此外还有独立构建的 **openSUSE**（zypper）、**Alpine**（apk，主打容器）、**Gentoo**（源码编译）等。

## 主流发行版速览

### Ubuntu

- **定位**：最流行的桌面与服务器发行版，「新手友好」的代名词。
- **优势**：文档和教程最多、软件源最全、社区最大，遇到问题几乎都能搜到答案。
- **版本策略**：每 6 个月一个版本，每 2 年一个 LTS（长期支持，5 年维护）。
- **适合**：入门者、开发机、绝大多数服务器（本站在部署手册里也推荐它）。

### Debian

- **定位**：Ubuntu 的「母体」，以极致稳定著称。
- **优势**：版本更新慢但极其可靠，被大量服务器和嵌入式设备采用。
- **适合**：追求稳定、不想频繁升级的服务器场景。

### Fedora

- **定位**：Red Hat 的「试验田」，新技术先行者。
- **优势**：内核与软件版本新，是体验 Linux 最新特性的窗口。
- **适合**：喜欢尝鲜的开发者、桌面用户。

### Arch Linux

- **定位**：极简、滚动更新、DIY 主义。
- **优势**：软件最新（滚动更新无大版本），wiki 是公认最好的 Linux 文档。
- **门槛**：安装全手动，需要自己搭出系统，不适合新手。
- **适合**：想深入理解 Linux 组成、享受「自己装出来的系统」的进阶用户。

### Alpine

- **定位**：极致轻量，专为容器设计。
- **优势**：镜像只有几 MB，Docker 官方镜像很多都基于它。
- **适合**：容器化部署场景。

## 怎么选？

- **想入门 / 当主力开发机** → Ubuntu 或 Linux Mint。
- **搭服务器 / 追求稳定** → Ubuntu LTS 或 Debian。
- **想体验最新技术** → Fedora。
- **想彻底搞懂 Linux** → Arch（前提是你愿意花时间读文档）。

> 没有「最好」的发行版，只有「最适合你当前阶段」的发行版。换发行版成本很低，先选一个用起来，比纠结更重要。
