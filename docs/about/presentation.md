# 答辩演示指南

本文档帮你把「Linux 命令图谱」项目讲清楚、演示到位。比赛考察三个核心维度：**内容质量、前端技术、Linux 环境部署能力**。下面按这三个维度组织你的答辩话术和演示动作。

## 一、内容质量

**要传达的点**：这不是一个普通的文档站，而是一份「可交互」的命令手册。

演示动作：
1. 打开首页，展示 hero 区的**伪终端**，直接敲 `ls -l`、`cd var/log`、`cat syslog`，证明它能真交互。
2. 进命令手册，展示 **63 条命令、7 大分类**，点开 `grep`，讲五段式结构（做什么→用法→选项→示例→说明）。
3. 用搜索框搜「递归」，展示本地搜索能力。

话术参考：
> 「市面上的命令手册大多是死文档，看完就忘。我做了一个能动手敲的——每条命令有统一结构，还有一个零依赖手写的伪终端，让读者先体验再理解。」

## 二、前端技术

**要传达的点**：用 VitePress（Vue 3 + Vite）框架，同时保留了「懂底层」的加分项。

演示动作：
1. 讲技术栈：VitePress 静态生成 + Vue 3 + 自研组件。
2. **重点展示伪终端源码**（`terminal-core.js`，806 行零依赖），讲虚拟文件系统、命令解释器、Tab 补全的实现思路。
3. 切换深浅主题，展示 CSS 变量方案。
4. 展示响应式（手机端布局）和无障碍（键盘导航）。

话术参考：
> 「我选择 VitePress 是双赢：一方面用上了现代框架和静态生成器，另一方面我又手写了一个 800 行的伪终端组件，证明不是只会调框架，底层的东西我也懂。」

## 三、Linux 环境部署能力（重点）

**要传达的点**：从裸机到公网 HTTPS，全流程自己搞定，且能「git push 即上线」。

演示动作（准备截图或现场操作）：
1. `systemctl status nginx` —— 服务在跑。
2. `nginx -t` —— 配置检查通过。
3. `systemctl list-timers | grep certbot` —— 证书自动续期已就绪。
4. `certbot renew --dry-run` —— 手动演练续期。
5. `git push prod main` —— 展示自动化部署链路输出。
6. 浏览器打开 `https://你的域名`，地址栏有小锁。

话术参考：
> 「我走通了完整的部署链路：买服务器 → 初始化（建 sudo 用户、关密码登录、配防火墙）→ 装 Nginx → 签发 HTTPS 证书并配自动续期 → 用 Git 钩子实现 push 即上线。站点现在跑在公网上，性能和无障碍都能到 90 分以上。」

## 验收清单（答辩前自查）

- [ ] `https://域名` 能打开，有小锁
- [ ] `http://` 自动跳转 `https://`
- [ ] 404 页正常
- [ ] 手机端布局正常
- [ ] Lighthouse 四项 90+
- [ ] `curl -I` 能看到 gzip/br
- [ ] 证书自动续期已配置
- [ ] 伪终端能交互（Tab 补全、历史、cd 生效）

## 可能被追问的问题

| 问题 | 回答要点 |
| --- | --- |
| 为什么选 VitePress？ | 命中「框架 + 生成器」两条，Vue 内核 + 静态输出，适合文档站 |
| 伪终端怎么实现的？ | 虚拟文件系统（对象树）+ 命令解释器 + 路径解析，纯 JS，无依赖 |
| HTTPS 证书为什么能自动续期？ | certbot 的 systemd timer，`certbot renew` 到期前自动执行 |
| 怎么做到 push 即上线？ | Git 裸仓库 + post-receive 钩子：检出→构建→rsync→重载 nginx |
| 服务器安全做了什么？ | 关 root 密码登录、建 sudo 用户、ufw 只开必要端口、隐藏版本号 |
