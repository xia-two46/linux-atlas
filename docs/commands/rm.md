> **危险**：`rm` 删掉的文件不会进回收站，也基本无法恢复。敲回车前先看一眼路径。

## 它做什么

删除文件或目录。删除目录必须加 `-r`。

## 用法

```console
rm [选项] 文件...
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-r` | 递归删除目录及其全部内容，也可写 `-R` |
| `-f` | 强制删除，不询问也不报错 |
| `-i` | 删除前逐个询问 |
| `-v` | 显示删除过程 |
| `--preserve-root` | 拒绝删除根目录（现代系统默认开启） |

## 示例

删除单个文件：

```console
$ rm notes.txt
```

删除整个目录：

```console
$ rm -r build/
```

逐个确认地删除：

```console
$ rm -i *.log
```

## 说明

- 广为流传的 `rm -rf /` 在现代 GNU coreutils 上会被 `--preserve-root` 拦下，但 `rm -rf /*` 或 `rm -rf ~/*` 之类的写法依然会造成真实破坏。**永远不要给来路不明的删除命令加 sudo。**
- 没有把握时先不删，把文件 `mv` 到一个临时目录，确认无误再清理。
- 想要"可回收的删除"，可以装 `trash-cli`，之后用 `trash-put` 代替 `rm`，删错了还能从回收站捞回来。
