## 它做什么

从每一行里截取指定的部分，可以按分隔符切分后的字段，也可以按字符位置。处理简单的分隔符文本比 awk 快。

## 用法

```console
cut [选项] [文件...]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-d 分隔符` | 指定字段分隔符，默认是 Tab |
| `-f 范围` | 指定字段，`-f1,3` 取第 1 和 3 列，`-f2-4` 取 2 到 4 列 |
| `-c 范围` | 按字符位置截取，如 `-c1-10` |
| `--complement` | 取反，输出**排除**指定部分后的内容 |
| `-s` | 跳过不含分隔符的行 |

## 示例

取 /etc/passwd 里的用户名和 shell：

```console
$ cut -d: -f1,7 /etc/passwd
```

取每行的前 20 个字符：

```console
$ cut -c1-20 access.log
```

反过来，去掉第 1 列保留其余部分：

```console
$ cut -d' ' -f1 --complement data.txt
```

## 说明

- 分隔符是空格时要注意：`-d' '` 只认单个空格，多个连续空格会产生空字段。这种情况用 `awk '{print $2}'` 更省事，它能自动吃掉多余空白。
- `cut` 无法处理变长分隔符的 CSV，`-s` 可以跳过那些没有分隔符的行。
- 字符位置从 1 开始计数。
