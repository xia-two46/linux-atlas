## 它做什么

修改文件或目录的读、写、执行权限，支持符号写法（如 `u+x`）和八进制数字写法（如 `755`）。

## 用法

```console
chmod [选项] 模式 文件...
```

## 权限的两种写法

八进制：三个数字分别对应属主、属组、其他人，`r=4`、`w=2`、`x=1` 相加而成。

| 数字 | 含义 |
| --- | --- |
| `755` | 属主可读写执行，其他人只读和执行（脚本、程序的常见权限） |
| `644` | 属主可读写，其他人只读（普通文件的常见权限） |
| `600` | 只有属主能读写（私钥、含密码的配置） |
| `700` | 只有属主能读写执行 |
| `777` | 所有人可读写执行，几乎总是错的 |

符号：`u` 属主、`g` 属组、`o` 其他人、`a` 全部，配合 `+` `-` `=` 使用。

## 示例

给脚本加执行权限：

```console
$ chmod +x deploy.sh
```

只给属主加执行权限：

```console
$ chmod u+x deploy.sh
```

私钥必须只有自己能读：

```console
$ chmod 600 ~/.ssh/id_ed25519
```

递归把目录设成 755、文件设成 644：

```console
$ find . -type d -exec chmod 755 {} \;
$ find . -type f -exec chmod 644 {} \;
```

## 说明

- **目录必须有 `x` 权限才能进入**。只有 `r` 的话能列出文件名，但读不到内容。
- `chmod 777` 解决的是"不知道该给谁权限"，代价是任何人都能改。配置文件和私钥绝对不能这么设。
- 想让新建文件默认就有合适权限，用 `umask`。`umask 022` 对应新建文件 644、目录 755。
