## 它做什么

按字典序对输入行排序后输出。它不会修改原文件，结果默认打到标准输出。

## 用法

```console
sort [选项] [文件...]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-r` | 倒序排列 |
| `-n` | 按数值大小排序，而不是字典序 |
| `-h` | 能识别 1K、2G 这类人类可读单位 |
| `-u` | 排序并去重，等价于 `sort` 之后接 `uniq` |
| `-k 2` | 按第 2 个字段排序 |
| `-t:` | 指定字段分隔符为冒号 |
| `-f` | 忽略大小写 |

## 示例

按数值排序，否则 10 会排在 9 前面：

```console
$ sort -n numbers.txt
```

按第 2 列数值倒序排列：

```console
$ sort -t: -k2 -nr data.txt
```

和 `du` 搭档，按占用空间从小到大排：

```console
$ du -sh * | sort -h
```

排序并去重：

```console
$ sort -u ip.txt
```

## 说明

- 处理数字时**一定要加 `-n`**，否则 100 会排在 20 前面。
- 不同语言环境的排序规则不一样，脚本里想要稳定结果可以前缀 `LC_ALL=C`。
- `sort` 处理大文件会自动使用临时文件做外部排序，不会一次性把内容塞进内存。
