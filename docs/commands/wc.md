## 它做什么

统计输入的行数、单词数与字节数。默认三个都输出，顺序是 行数 词数 字节数 文件名。

## 用法

```console
wc [选项] [文件...]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-l` | 只统计行数 |
| `-w` | 只统计单词数 |
| `-c` | 只统计字节数 |
| `-m` | 只统计字符数，区别于字节数 |
| `-L` | 输出最长那一行的长度 |

## 示例

统计日志有多少行：

```console
$ wc -l access.log
```

数一数当前目录有多少个条目：

```console
$ ls -1 | wc -l
```

统计项目代码总行数：

```console
$ find src -name "*.js" | xargs wc -l | tail -1
```

## 说明

- `wc -l` 统计的是换行符的个数。文件最后一行如果没有换行结尾，会少算一行。
- 中文字符在 UTF-8 下占 3 个字节，`-c` 和 `-m` 的结果会差很多，数字数要用 `-m`。
- 想统计某个关键词出现的次数，`grep -c "关键词" 文件` 比 `wc` 更直接。
