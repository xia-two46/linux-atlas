## 它做什么

设置或修改用户密码。root 可以改任何人的密码，普通用户只能改自己的，且要先验证旧密码。

## 用法

```console
passwd [选项] [用户名]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-l` | 锁定账号，禁止密码登录 |
| `-u` | 解锁账号 |
| `-d` | 删除密码，使其变为空密码 |
| `-e` | 强制下次登录时必须改密码 |
| `-S` | 查看密码状态 |
| `-x 天数` | 设置密码有效期 |

## 示例

改自己的密码：

```console
$ passwd
```

给刚建好的用户设密码：

```console
$ sudo passwd deploy
```

临时给同事开号，让他首次登录时必须改密码：

```console
$ sudo useradd -m -s /bin/bash temp && sudo passwd -e temp
```

## 说明

- 输入密码时屏幕上不会有任何回显，连星号都没有，这是正常的，照常输完回车即可。
- 锁定账号（`-l`）比删除账号安全：账号保留、数据保留，只是不能再用密码登录。
- 服务器上更推荐的做法是**直接关掉密码登录**，只允许 SSH 密钥登录——安全性高一整个量级。
- 密码哈希存在 `/etc/shadow`，只有 root 能读。
