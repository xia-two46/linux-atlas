## 它做什么

切换到另一个用户的身份并启动新的 shell。不带用户名时默认切到 root。

## 用法

```console
su [选项] [用户名]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-` 或 `-l` | 完整登录，加载目标用户的环境变量并进入其家目录 |
| `-c 命令` | 以目标用户身份执行一条命令后退出 |
| `-s shell` | 指定要启动的 shell |

## 示例

完整切换到 root（推荐写法）：

```console
$ su -
```

只执行一条命令：

```console
$ su - www-data -c "nginx -t"
```

## 说明

- **`su -` 和 `su` 差别很大。** 不加横杠是"半切换"，环境变量、工作目录都还是原来的，容易出现命令找不到的怪现象。要切换就老老实实用 `su -`。
- **日常提权请用 `sudo` 而不是 `su`**：sudo 权限只作用于单条命令、会留下审计日志、不需要把 root 密码告诉别人。
- 从 root 切回普通用户不需要密码，直接 `su - deploy` 或 `exit`。
- 想知道自己现在是哪个用户，用 `whoami` 或 `id`。
