## 它做什么

把文件或目录复制到指定位置。复制目录必须加 `-r`，否则会跳过目录并报错。

## 用法

```console
cp [选项] 源... 目标
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-r` | 递归复制目录，也可写 `-R` |
| `-a` | 归档模式，保留权限、时间戳与链接，等价于 `-dR --preserve=all` |
| `-i` | 覆盖前询问 |
| `-n` | 不覆盖已存在的文件 |
| `-u` | 只复制目标不存在、或比目标更新的文件 |
| `-v` | 显示复制过程 |
| `-p` | 保留原文件的权限与时间戳 |

## 示例

就地备份一个文件：

```console
$ cp report.txt report.txt.bak
```

复制整个目录：

```console
$ cp -r ~/projects /mnt/backup/
```

保留全部属性做完整备份：

```console
$ cp -a /etc /root/etc-backup
```

只同步有更新的文件：

```console
$ cp -uv src/*.js dist/
```

## 说明

- 目标是目录时，源文件会被放进该目录；目标是具体文件路径时，相当于"复制并改名"。
- `-a` 是备份时的首选，它会连符号链接、权限、修改时间一起保留，`-r` 做不到这点。
- 复制大量文件或做远程同步时，`rsync -a` 更合适，它支持增量传输和断点续传。
