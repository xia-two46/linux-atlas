## 它做什么

文件不存在时创建一个空文件；文件已存在时，把它的访问时间和修改时间更新为当前时刻。

## 用法

```console
touch [选项] 文件...
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-a` | 只更新访问时间 |
| `-m` | 只更新修改时间 |
| `-c` | 文件不存在时不创建 |
| `-t 时间` | 指定时间，格式 `[[CC]YY]MMDDhhmm[.ss]` |
| `-r 文件` | 参照另一个文件的时间 |

## 示例

创建一个空文件：

```console
$ touch newfile.txt
```

把时间戳改成指定时刻：

```console
$ touch -t 202610161200 report.txt
```

让两个文件的时间一致：

```console
$ touch -r a.txt b.txt
```

## 说明

- 最常见的用途其实不是建文件，而是"把文件摸一下"——比如想让 `make` 认为目标已更新，或触发依赖 mtime 的程序重新加载配置。
- `touch` 不会清空已存在文件的内容，这点新手容易误解。
- 想看时间戳有没有真的改了，配合 `stat` 或 `ls -l` 验证。
