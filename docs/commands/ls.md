## 它做什么

`ls` 列出指定路径下的文件与目录。不带任何参数时，列出当前工作目录的内容。

## 用法

```console
ls [选项] [文件或目录...]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-l` | 长格式输出，显示权限、属主、大小与修改时间 |
| `-a` | 一并显示以 `.` 开头的隐藏文件 |
| `-h` | 配合 `-l` 使用，把大小显示为 4K、12M 这样的单位 |
| `-t` | 按修改时间排序，最新改动的排在最前 |
| `-r` | 反转排序结果 |
| `-R` | 递归列出所有子目录 |
| `-1` | 每行只输出一个条目，方便管道处理 |

## 示例

列出当前目录的详细信息，包含隐藏文件：

```console
$ ls -lah
drwxr-xr-x  2 user user 4.0K Oct 16 09:10 .
drwxr-xr-x 14 user user 4.0K Oct 16 09:02 ..
-rw-r--r--  1 user user  220 Oct 16 09:10 .bashrc
-rw-r--r--  1 user user 1.2K Oct 16 09:12 notes.txt
```

找出最近修改的 5 个文件：

```console
$ ls -lt | head -5
```

只列出目录本身而不展开内容：

```console
$ ls -d */
```

## 说明

- `ls -l` 的长格式第一列共 10 个字符，第 1 位是文件类型（`-` 普通文件、`d` 目录、`l` 符号链接），后 9 位每 3 个一组，分别是属主、属组、其他人的 `rwx` 权限。
- 想让输出按大小排序用 `-S`，倒序再加上 `-r`，即 `ls -lShr`。
- 颜色输出来自 `--color=auto` 别名，很多发行版已经默认加进 `.bashrc`。
