# 在线终端

这是一个运行在**你浏览器里**的伪终端——不需要安装 Linux，也不需要任何后端服务。

它内置一个虚拟文件系统和一个命令解释器，你的操作会**真实地改变**这个虚拟环境（`mkdir` 会真的建目录、`rm` 会真的删文件），但只存在于当前页面，**刷新即复原**。

## 它支持什么

| 能力 | 说明 |
| --- | --- |
| 命令执行 | 38 条命令，覆盖查看、编辑、检索、系统信息四大类 |
| Tab 补全 | 自动补全命令名与路径 |
| 历史记录 | 按 ↑ / ↓ 翻阅输入历史 |
| 路径解析 | 绝对路径、相对路径、`~`、`.`、`..` 都认 |
| 快捷键 | `Ctrl+L` 清屏、`Ctrl+C` 取消当前输入 |

## 快速上手

输入 `help` 查看完整命令列表，然后试试：

```console
$ ls -l
$ cd var/log
$ cat syslog
$ neofetch
```

这个伪终端本身，就是本站「内容 + 前端技术」结合的一个体现——它用纯 JavaScript 手写了一个微型 shell，没有依赖任何第三方库。
