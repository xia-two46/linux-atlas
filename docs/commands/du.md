## 它做什么

统计文件或目录占用的磁盘空间。`df` 回答"分区还剩多少"，`du` 回答"谁占了多少"。

## 用法

```console
du [选项] [路径...]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-h` | 人类可读格式 |
| `-s` | 只显示汇总值，不逐层列出 |
| `-a` | 把文件也单独列出，而不只是目录 |
| `-d 深度` | 限制统计层级，`-d 1` 只看一层 |
| `-x` | 不跨到其他文件系统 |
| `--exclude=模式` | 排除匹配的文件 |

## 示例

看当前目录下一级各自占多少：

```console
$ du -h -d 1
```

按大小排序，快速定位占空间的大户：

```console
$ du -sh * | sort -h
```

只统计某个目录的总大小：

```console
$ du -sh /var/log
```

统计时跳过 node_modules：

```console
$ du -sh --exclude=node_modules .
```

## 说明

- `du` 统计的是实际占用的磁盘块数，和一个个文件大小相加的结果会略有出入，稀疏文件尤其明显。
- 扫大目录时比较慢，加 `-x` 能避免统计到挂载的其他分区（比如网络盘），速度快很多。
- 想要交互式分析磁盘占用，`ncdu` 比 `du | sort` 直观得多，它可以用方向键逐层下钻。
