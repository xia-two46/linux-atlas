## 它做什么

实时显示进程的 CPU、内存占用和系统负载，默认每 3 秒刷新一次。它是排查"机器为什么卡"的第一站。

## 用法

```console
top [选项]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-d 秒` | 指定刷新间隔 |
| `-p PID` | 只看指定进程 |
| `-u 用户` | 只看某用户的进程 |
| `-b` | 批处理模式，输出纯文本，便于脚本采集 |
| `-n 次数` | 刷新指定次数后退出 |
| `-o 字段` | 按指定字段排序，如 `-o %MEM` |

## 界面里的操作键

`P` 按 CPU 排序、`M` 按内存排序、`k` 杀进程（会问 PID）、`1` 展开每个 CPU 核心、`q` 退出。

## 示例

每 1 秒刷新：

```console
$ top -d 1
```

抓一次快照写进日志，适合做监控脚本：

```console
$ top -b -n 1 > snapshot.txt
```

## 说明

- 看第一行**load average** 三个数，分别是 1、5、15 分钟平均负载。对 N 核机器来说，超过 N 就说明有进程在排队等 CPU。
- `%Cpu(s)` 里 `wa`（iowait）持续偏高，通常意味着磁盘 IO 是瓶颈，而不是 CPU。
- 想更好看更好用，装 `htop`：支持鼠标、彩色、树形视图，交互体验完胜 top（`apt install htop`）。
