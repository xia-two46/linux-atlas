## 它做什么

逐行比较两个文件（或目录），输出哪里不一样。它是 `git diff` 和补丁文件的底层工具。

## 用法

```console
diff [选项] 文件1 文件2
diff [选项] 目录1 目录2
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-u` | 统一格式输出，带 3 行上下文，最常用也最好读 |
| `-y` | 并排双栏显示 |
| `-r` | 递归比较子目录 |
| `-q` | 只报告"是否不同"，不显示具体改动 |
| `-i` | 忽略大小写差异 |
| `-w` | 忽略所有空白差异 |
| `-B` | 忽略空行 |

## 输出怎么读

`<` 表示第一个文件的内容，`>` 表示第二个文件的。行号 `12,15c12,14` 里的 `c` 表示修改（change），另有 `a` 增加（add）、`d` 删除（delete）。

## 示例

生成一份可读的差异报告：

```console
$ diff -u nginx.conf nginx.conf.new
```

比较两个版本仓库：

```console
$ diff -rq old-app/ new-app/
```

把差异存成补丁文件，之后可以用 `patch` 应用：

```console
$ diff -u a.c b.c > fix.patch
$ patch a.c < fix.patch
```

## 说明

- 单独比较目录要加 `-r`，否则它只会报告两个目录下同名文件的差异。
- `-w` 在比较被重新格式化过的代码时很好用，能滤掉纯粹的缩进变化。
- 想要可视化工具，可以装 `vimdiff` 或 `meld`。
