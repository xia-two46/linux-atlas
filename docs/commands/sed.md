## 它做什么

逐行读取文本，按脚本处理后输出。最常见的用途是批量替换，加 `-i` 可以直接改写文件。

## 用法

```console
sed [选项] '脚本' [文件...]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-n` | 静默模式，只输出被 `p` 指令指定的行 |
| `-i` | 直接修改文件，写 `-i.bak` 会先留一份备份 |
| `-e` | 追加一段脚本 |
| `-E` | 使用扩展正则 |

## 常用脚本

| 脚本 | 作用 |
| --- | --- |
| `s/旧/新/` | 替换每行第一个匹配 |
| `s/旧/新/g` | 替换每行所有匹配 |
| `s/旧/新/I` | 忽略大小写替换 |
| `10d` | 删除第 10 行 |
| `/模式/d` | 删除匹配到的行 |
| `/模式/p` | 打印匹配到的行，配合 `-n` |
| `10,20p` | 打印第 10 到 20 行 |

## 示例

把文件里所有 foo 换成 bar：

```console
$ sed 's/foo/bar/g' file.txt
```

直接改文件，并保留一份 .bak 备份：

```console
$ sed -i.bak 's/foo/bar/g' file.txt
```

只看第 10 到 20 行：

```console
$ sed -n '10,20p' long.log
```

删掉所有空行：

```console
$ sed '/^$/d' file.txt
```

去掉行首的空白：

```console
$ sed 's/^[ \t]*//' file.txt
```

## 说明

- 替换语法的分隔符可以换成别的字符。路径里有一堆 `/` 时，写成 `s#/a/b#/c/d#g` 会清爽很多。
- 替换部分里的 `&` 代表整个匹配内容，比如给所有数字套上方括号：`sed 's/[0-9]\+/[&]/g'`。
- 不带备份后缀的 `-i` 改动不可撤销。大批量操作前，先跑一遍不带 `-i` 的版本，把结果打到屏幕上确认。
